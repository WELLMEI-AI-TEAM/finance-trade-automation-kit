# 合同打印整理

在原合同副本上整理打印设置，原件始终保留。默认A4纵向、10mm页边距：优先选择清晰的一页，较长时两页，必要时更多页。可尝试6mm窄页边距增加可打印宽度；宽度仍导致字太小时尝试A4横向并在回复中说明。页数不是质量目标，不为凑一页或两页降低清晰度。

只调整纸张、方向、打印区域、页边距、缩放和水平分页；保留文字、数字、日期、公式、字体、行高列宽、合并、图片及签章。**这是独立打印步骤，不改变PI转出口合同技能的原样生成要求。** 未明确要求打印时不调用，也不自动发送实体打印任务。

## 输入与目录

用户指定合同文件、合同目录或对话附件的真实本机路径。只处理明确提供的文件；附件须先取得本机可读位置，不扫描历史原件或整个桌面。不要因为名字含“合同”就处理订单确认书、PI或购货合同；打印某类单据必须在用户指定范围内。

输出目录默认在指定合同目录旁新建“打印结果”，也可使用用户指定目录。每批只包含 `Excel打印版/` 与 `PDF打印版/`。工作区默认 `%LOCALAPPDATA%/ContractPrintLayout/工作区`，也可显式 `--work-root`，须与原文件和成品目录分开。JSON、日志、候选、PNG和核验资料留工作区。原文件不删除，打印步骤没有“清空待处理”的权限。

Python优先使用本技能 `binding.local.json` 中的python，未绑定时使用本机可用Python 3.10+，依赖见requirements.txt（openpyxl、xlrd、PyMuPDF、lxml）。需要宿主Windows及已安装Excel或WPS；只能访问Linux或缺少原生Office时说明限制，不生成假预览。

## 执行

1. 使用本技能入口，先只生成候选草稿：

   ```powershell
   python "<本技能目录>/scripts/print_contracts.py" prepare --input "<合同文件或目录>" --output "<打印结果目录>"
   ```

   支持多个输入。诊断用`check`。`--engine auto`优先Excel，失败后尝试WPS；可显式指定Excel或WPS。程序仅操作已核实归本批所有的新Office进程，不复用、关闭或杀掉用户会话，不改变Windows默认打印机。不因失败修改安全策略或安装其他软件。脚本失败先读取其工作区日志，不绕过校验直接复制候选。

2. 读取返回record路径中的batch.json。程序对每份合同尝试A4纵向（10mm及6mm边距）、横向及1页、2页、自然分页，跳过重复设置，避开跨行合并、连续商品说明和图片区域；只将打印参数移植到原始文件副本，保留其他内容，再由Office重新导出最终PDF。对PDF字号、页数、文本覆盖、空白页、导出后原生分页及工作簿指纹检查后，选出`awaiting_visual_review`。`pending`的具体原因与候选检查放工作区。

3. **实际查看每份拟发布PDF的全部页。** 使用记录中的previews或PDF读图工具，核对商品、条款、总计及签章完整，分页未切开同一商品说明或签章，字体清晰、没有截断或空白页。缩放改变可能暴露原有行高/列宽截断，不能仅凭文字提取成功忽略。`prepare`成功、字号合格、页数少或生成PNG都不等于视觉通过。

   既有打印区域之外可能存放短装备注等非打印内容。`range_exclusions`列出这些内容：保留原打印区域，逐项判断是否确为不应打印的备注，并在range_review写明依据；若是应打印的合同正文/签章，先待核对，不能默默丢弃或自行扩大到无关资料。

   自动字号门槛为字符加权中位数8pt、10分位7pt，这是筛查而非完整清晰度证明。仅用户明确允许时才降低`--min-median`或`--min-p10`；不能为提高成功率静默降低。若两页仍太小，可更多页或横向；仍无法清楚打印的待核。源字号本来很小不意味着可继续缩小后交付。

   自动文本检查覆盖源PDF中不同词项是否仍出现，不能单凭它证明重复商品行都完整。检查checks.json中的reduced_occurrences；减少可能来自页眉重复次数变化，也可能是重复商品遗漏，须结合原件逐页核实。正文已有的固定行高/列宽截断无法仅调整打印设置修复，此时待核并说明，不擅自改字体或表格。

4. 在work_dir创建reviews.json，键为文件id。只有实际查看过全部页才能写passed，例如：

   ```json
   {"1":{"status":"passed","pages":[1,2],"notes":"逐页确认商品和总计完整，分页位于商品之间，签章完整，正文可读。","range_review":"Z列三处为既有短装备注，不属于原打印合同范围，保持原设置。"}}
   ```

   pages须与真实PDF一致；无区外内容时省略range_review。无法确认的写failed或不列入passed，并在对话说明原因。不要批量生成并未观察过的结论。

5. 发布已核验的副本：

   ```powershell
   python "<本技能目录>/scripts/print_contracts.py" finish --record "<record>" --reviews "<work_dir/reviews.json>"
   ```

   入口再次核实文件哈希、核验页数及源文件稳定性，发布时保留原文件名。同名不同来源稳定加后缀，不覆盖。失败及待核资料留工作区，不把未核验文件放进“PDF打印版”。

回复实际发布份数、待核份数、1页/2页/更多页分布、横向数量和结果目录。建议用户优先打印PDF，并在打印对话框选择实际大小/100%，避免再次缩放。实际物理打印效果受打印机可打印边距影响；未发送打印任务就不能声称已完成打印。
