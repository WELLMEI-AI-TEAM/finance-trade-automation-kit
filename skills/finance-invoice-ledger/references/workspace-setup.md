# 首次设置与换电脑安装

仅首次设置、账户未配置或用户主动切换工作区时读取。正常处理复用本机绑定。

## 会话流程

1. 缺少绑定时询问：“请问要在哪个文件夹下建立‘台账处理’？请提供完整路径。”用户已给出目录则直接使用，不再次询问。
2. 选择本机 Python 3.10 或更高版本。示例中的 `python` 使用当前电脑可用解释器，不照抄旧电脑用户名下的路径。初始化脚本仅使用标准库。
3. 用户指定父目录后执行：

   ```powershell
   python "<本Skill目录>/scripts/setup_workspace.py" --parent "<用户指定的父目录>"
   ```

   父目录必须是本机已存在的完整目录路径。若用户给出的是明确要复用的根目录，使用 `--root "<已有根目录>"`，不再拼接“台账处理”。初始化不会覆盖已有配置或财务文件；已绑定另一工作区时停止，不自动换账。

4. 目录创建结果不代表已能处理发票。`account_setup_required` 表示还需要用户提供此电脑实际可访问的财务台账服务地址、财务用户名，以及已有凭据文件路径（或密码环境变量名）。不要从旧电脑安装包、测试配置、其他用户的工作区获取账户，不创建管理员或测试账户。
5. 用户提供后，用同一初始化脚本完成配置：

   ```powershell
   python "<本Skill目录>/scripts/setup_workspace.py" --root "<已建立根目录>" --service-url "<服务根地址，不含/api/v1>" --username "<财务用户名>" --credentials-file "<本机已有凭据文件完整路径>"
   ```

   凭据文件格式为一行 `用户名 密码`，脚本读取它，不在会话打印密码。若用户采用已设置的密码环境变量，则以 `--password-env "<变量名>"` 代替 `--credentials-file`；不将密码作为命令参数。用户已有完整财务配置时可以使用明确指定的配置，不从别的账户复制。
6. 运行依赖为 `httpx`、`openpyxl`、`PyMuPDF`。新电脑还须能够访问原台账服务；Skill 安装包不包含后台服务或模型账户。首次真实调用由后台检查账户部门，必须为 finance。初始化的 `configured` 仅表示配置字段已填写，不表示已联网验证或成功处理。

## 根目录结构

```text
用户指定的父目录/
└─ 台账处理/
   ├─ 待处理/                 输入文件，支持子目录；本轮完成并确认保存后自动清理
   ├─ 发票/                   全部月份共同作为归档查重范围
   │  ├─ 2026.09/             按票面年月按需创建
   │  └─ 2026.10/
   ├─ 台账文件/               首次成功入账后创建Excel，或追加已有兼容账本
   ├─ 异常未处理发票/
   │  └─ 2026-10-29_14-35-08/ 本轮未解决原件及原因，按北京时间精确到秒
   ├─ 备份/                   最近10组受管备份，超出整组轮换
   │  └─ 2026-10-29_14-35-08/ 北京时间精确到秒，同秒冲突加后缀
   │     ├─ 本次处理的发票/    本轮输入原件快照，含异常输入，同内容去重
   │     └─ 旧台账/            替换前账本原件；首次建账时留空
   └─ .运行记录/              隐藏的本机配置、恢复状态、复核队列及证据
```

未收到发票时不生成空白假台账，不预建无用的月份目录。不要删除运行记录强制重跑。

常规入口在归档、入账、所需备份及恢复记录/结果保存后清理本轮待处理输入；异常已完整转存原件、原因和队列后也移出待处理。保留待处理目录、本轮未处理的新文件，以及报错、被修改或目标未保存完整的原件。根目录文件、外部附件及链接目标不自动删除；不要人工整目录清空。

仅实际写入台账时建立备份组，纯重复处理不重复备份。每组只含上述两个子目录，索引留在隐藏运行记录。人工修改或新增文件的备份停止自动轮换并报告。旧版散放备份核验后移入时间目录；无法可靠关联历史输入时发票子目录留空，不补入猜测的发票。

仅出现新异常时创建一个时间目录；独立任务同秒命名冲突时加 `_02` 等后缀。续跑原异常沿用其时间目录；解决后只移除受管副本和空目录，保留其他异常或人工文件。旧版散放异常校验原件哈希后分组，先保存新副本和状态/队列路径再清除旧副本；中断时复用整理记录恢复，不额外调用识别。

Windows 下 `.运行记录` 设置隐藏属性，资源管理器关闭“隐藏的项目”时不显示。新锁统一保存在本机应用数据目录 `InvoiceLedgerSkill/locks`，按资源完整路径生成固定哈希文件名，同一账本/归档树仍共用锁。升级时已有 `.guard` 作为旧版兼容锁设为隐藏并保留，不删除正在参与并发保护的文件。业务目录不再新增锁文件。常规处理不在根目录或业务目录追加报告、辅助脚本、临时图像；需要的复核资料放 `.运行记录`。

## 月份格式与迁移

新配置写入 `archive_month_layout: "year.month"`，得到 `发票/2026.10`。已有配置缺少此字段时继续使用 `year/month`（`发票/2026/10`），保留原路径；两种格式均在同一发票树内递归查重。不要因版本更新搬动旧原件或更换绑定。

## 分发要求

分发包不包括 `binding.local.json`、`profiles`、凭据、状态、测试账本、原始发票、`__pycache__`。新电脑安装后的目录选择由会话发起；脚本返回问题，不使用阻塞式终端 `input()`。保留当前电脑的绑定仅用于本机升级，不放进可移植安装包。
